# 停车场管理系统

一个功能完整的停车场管理系统，支持多种车辆类型的智能收费逻辑。

## 🚗 系统特性

### 支持的车辆类型

1. **月租车 (Monthly)**
   - 按月包月收费，适合长期停车用户
   - 基础月租费用：¥300/月
   - 超出月租时间按日费率计算
   - 享受月租折扣和忠诚度优惠

2. **储值车 (Prepaid)**
   - 预付费模式，按小时计费
   - 小时费率：¥5/小时
   - 日封顶：¥50/天
   - 支持充值赠送

3. **临停车 (Temporary)**
   - 临时停车，按小时计费
   - 小时费率：¥8/小时
   - 日封顶：¥80/天
   - 首小时免费
   - 支持夜间和周末费率调整

4. **免费车 (Free)**
   - 特殊车辆，不收费
   - 需要审批
   - 有最大停车时长限制

### 🎯 核心功能

- **智能计费系统**：支持时间段费率、优惠活动、节假日折扣
- **多停车场管理**：支持创建和管理多个停车场
- **车辆注册管理**：完整的车辆信息管理系统
- **实时统计报表**：收入统计、车位使用率等
- **灵活配置**：所有计费规则和参数都可配置

## 📋 计费规则详解

### 基础计费逻辑

#### 月租车
- **基础费用**：¥300/月
- **超出处理**：超过30天按¥20/天计算
- **优惠折扣**：月租8折 + 忠诚度折扣

#### 储值车
- **计费方式**：按小时计费，¥5/小时
- **日封顶**：¥50/天
- **充值优惠**：充值¥100以上赠送5%

#### 临停车
- **免费时间**：首小时免费
- **计费方式**：¥8/小时
- **日封顶**：¥80/天
- **时段调整**：支持高峰、平峰、夜间费率

### 时间段费率

| 时间段 | 时间范围 | 费率倍数 | 说明 |
|--------|----------|----------|------|
| 早高峰 | 07:00-09:00 | 1.5x | 上班高峰期 |
| 平峰时段 | 10:00-16:00 | 0.8x | 工作时间 |
| 晚高峰 | 17:00-19:00 | 1.3x | 下班高峰期 |
| 夜间时段 | 22:00-06:00 | 0.5x | 夜间优惠 |

### 优惠活动

- **新用户优惠**：注册30天内享受9折优惠
- **节假日优惠**：元旦、劳动节、国庆节享受8折优惠
- **忠诚度折扣**：月租用户根据签约时长享受折扣
  - 3个月以上：95折
  - 6个月以上：9折
  - 12个月以上：85折

## 🚀 快速开始

### 环境要求

- Python 3.7+
- 无额外依赖包

### 安装和运行

1. **克隆项目**
```bash
git clone <repository-url>
cd parking-system
```

2. **运行基础系统**
```bash
python parking_system.py
```

3. **运行增强版计算器**
```bash
python enhanced_fee_calculator.py
```

4. **测试配置**
```bash
python config.py
```

### 基本使用示例

```python
from parking_system import ParkingSystem, VehicleType

# 创建系统
system = ParkingSystem()

# 创建停车场
system.create_parking_lot("主停车场", 100)

# 注册车辆
system.register_vehicle("京A12345", VehicleType.MONTHLY)

# 车辆入场
main_lot = system.parking_lots["主停车场"]
main_lot.enter_parking("京A12345", VehicleType.MONTHLY)

# 车辆离场并计算费用
fee = main_lot.exit_parking("京A12345")
print(f"停车费用: ¥{fee:.2f}")
```

## 📊 系统配置

### 车辆类型配置

所有配置都在 `config.py` 文件中，可以轻松调整：

```python
VEHICLE_TYPES = {
    "monthly": {
        "monthly_fee": 300.0,        # 月租费用
        "extra_daily_rate": 20.0,    # 超出日费率
        "discount_rate": 0.8,        # 月租折扣
    },
    "prepaid": {
        "hourly_rate": 5.0,          # 小时费率
        "daily_cap": 50.0,           # 日封顶
    },
    # ... 更多配置
}
```

### 时间段配置

```python
TIME_PERIODS = {
    "peak_hours": {

        "end": "09:00",
        "rate_multiplier": 1.5,      # 费率倍数
    },
    # ... 更多时间段
}
```
